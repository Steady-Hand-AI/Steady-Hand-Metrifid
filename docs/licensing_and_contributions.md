# Licensing, ownership, and contributions

## Controlling files

The legal and contribution-policy files are:

- [`LICENSE`](../LICENSE): the complete Apache License 2.0 terms that govern the Metrifid code and
  documentation distributed from this repository;
- [`NOTICE`](../NOTICE): project attribution supplied with the distribution;
- [`DCO`](../DCO): the unmodified Developer Certificate of Origin 1.1 used to certify contribution
  provenance.

This document explains the repository policy. It does not replace those files.

## Software license

Metrifid is distributed under Apache License 2.0. The license permits use, modification, and
redistribution under its terms and includes patent, attribution, warranty-disclaimer, and trademark
provisions.

The Apache license text already present in `LICENSE` is complete. The placeholder language in its
appendix is part of the standard license text and must not be filled in or removed. Project-specific
attribution belongs in `NOTICE`.

## Contribution policy

Contributions intentionally submitted for inclusion in this repository are accepted under
Apache-2.0. Every commit in a pull request must include a Developer Certificate of Origin 1.1
sign-off. Create one with:

```bash
git commit -s
```

The resulting commit message contains:

```text
Signed-off-by: Your Name <you@example.com>
```

The DCO certifies that the contributor has the right to submit the contribution under the project
license. It is not a copyright assignment or a contributor license agreement. Contributors retain
copyright in their contributions while licensing them under Apache-2.0. The public sign-off record
is maintained with the project as described by the DCO.

Do not submit code, documentation, generated assets, or copied material that you do not have the
right to contribute. Unsigned commits are not merged.

## Contributor agreement boundary

This release does not use a contributor license agreement and does not request copyright assignment.
A DCO sign-off does not give the project owner exclusive relicensing rights over an outside
contributor's work. If the project later needs those rights, external contributions must pause until
a legally reviewed contributor agreement is adopted.
