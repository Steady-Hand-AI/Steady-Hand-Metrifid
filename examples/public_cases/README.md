# Complaint-backed public cases

These six owned MuJoCo microfixtures model failure mechanisms reported by robotics users and maintainers. They are mechanism analogues, not reproductions of Newton, USD, Isaac, or Robosuite. Every case runs the same installed Metrifid sequence: Certify, undeclared Model Review, then an exact maintainer-declared Model Review.

The permanent cases are deterministic, CPU-local, network-free, and version-neutral. Generated results are written only to an explicit absent workspace.
